# Overfitting and Regularization

**The Math Behind Models That Generalize**

A model that is perfect on its training data can be useless on new data. This project explores why that happens and how to detect and prevent it, using the mathematics behind machine learning: linear algebra, calculus and probability.

Final project for the **Math Concepts for Developers** course.

## Contents
- Linear regression from scratch (normal equation and maximum likelihood)
- Polynomial regression and overfitting
- The bias-variance tradeoff
- Regularization: Ridge (L2) and Lasso (L1)
- Model selection with k-fold cross-validation
- Application to a real-world dataset

## How to run
1. Install the dependencies: `pip install numpy matplotlib scikit-learn`
2. Open `main.ipynb` in Jupyter or VS Code and run all cells.
